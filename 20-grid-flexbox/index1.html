Combinación de CSS Grid y Flexbox

Introducción

Este ejemplo demuestra cómo Grid se utiliza para la estructura general de la página mientras Flexbox se encarga de alinear elementos dentro de cada sección.

CSS Grid permite dividir la página en columnas y filas. En este ejemplo el contenido principal siempre permanece centrado gracias a la variable --cols, que cambia mediante Media Queries.

CSS Grid organiza la estructura de la página y Flexbox organiza los elementos dentro de cada sección.

Al aumentar el tamaño de la pantalla, las columnas laterales crecen para mantener el contenido perfectamente centrado y con un ancho máximo.

La cabecera y el pie ocupan todo el ancho utilizando grid-column: 1 / -1;, mientras que el contenido se coloca únicamente en las columnas centrales.
